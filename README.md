# 🧩 Jigsaw Puzzle

An interactive web-based jigsaw puzzle game where users solve an image by dragging and arranging shuffled puzzle pieces into their correct positions.

---

## 📌 Overview

This project recreates the classic jigsaw puzzle experience in a browser. An image is divided into multiple pieces, shuffled randomly, and presented to the user. The objective is to correctly rearrange all the pieces to complete the original image.

The project demonstrates frontend development concepts including drag-and-drop interactions, dynamic DOM manipulation, and responsive UI design.

---

## ✨ Features

- 🧩 Interactive drag-and-drop puzzle
- 🎲 Randomized puzzle pieces
- 🎨 Image-based gameplay
- 📱 Responsive interface
- 🔄 Restart and reshuffle functionality
- ⚡ Smooth user experience

---

## 🛠 Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask

---

## 🎮 How to Play

1. Open the application.
2. A shuffled puzzle is displayed.
3. Drag and place each piece into its correct position.
4. Complete the puzzle to reveal the original image.
